# Аналіз утворення та оброблення відходів в Україні за 2019–2024 рр.

Цей репозиторій містить аналітичний проєкт та дослідження даних щодо динаміки утворення, утилізації, спалювання та видалення відходів в Україні за 6-річний період.

---

# Мета проєкту

Здійснити комплексний якісний та кількісний аналіз обсягів і структури утворення відходів (I–IV класів небезпеки), оцінити ефективність їх оброблення (утилізація, рециклінг, спалювання, захоронення) та виявити ключові тренди й структурні зсуви під впливом економічних чинників та повномасштабного вторгнення.

---

# Джерело даних

Сайт Державної Служби Статистики України stat.gov.ua.

## Опис показників (Data Dictionary)

У цьому дослідженні аналізується динаміка чотирьох ключових показників поводження з відходами. Усі дані вимірюються у **тис. тонн** (або вкажіть вашу одиницю виміру, наприклад, тонни).

| Показник | Змінна в коді | Опис / Тлумачення |
| :--- | :--- | :--- |
| **Обсяг утворених відходів** | `waste_generated` | Загальна маса відходів, що утворилися внаслідок економічної діяльності підприємств та життєдіяльності домогосподарств за звітний рік. |
| **Обсяг відновлених відходів** | `waste_recovered` | Маса відходів, що були перероблені, утилізовані або залучені до повторного використання (рециклінгу). |
| **Обсяг спалених відходів** | `waste_incinerated` | Маса відходів, знищених шляхом термічного оброблення (як з метою отримання енергії, так і без неї). |
| **Обсяг видалених відходів** | `waste_disposed` | Маса відходів, що була остаточно розміщена на спеціально обладнаних полігонах та сміттєзвалищах (захоронення). |
